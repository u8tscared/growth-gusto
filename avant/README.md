# Growth Gusto

Kitchen management web app for restaurants: HACCP fridge readings, goods reception, traceability with QR labels, stock and inventory, cleaning schedule, and the sanitary register.

**App:** https://u8tscared.github.io/growth-gusto/

To install it on a phone, open the link, then use *Partager › Sur l'écran d'accueil* (iPhone) or *Installer l'application* (Android).

Data is stored on the device in this test version.

To test locally, run `node tools/run.js tools/smoke.js`. This needs Playwright.
