# Design « Version 2 » — brief for every agent (2026-11-05)

Marceau picked mock-up **Version 2** for the whole app. Same features, same flows, same data: **only the design changes**. It must feel made by a top UX designer (not AI-made), playful, very clear, little text, smooth motion. French UI only.

The core layer is **css/v2.css** (loaded last; owned by the lead, do not edit). It already sets tokens and restyles the primitives (.glass, .btn, .iconbtn, .chip, .seg, .input, .pill, .ic, .li, .sheet, .toast, tab bar, sidebar, keypad, .step). Read it first. Your job: make YOUR area files match it, removing the old « Aurore » look (violet gradients, glass blur, glowing shadows, multicolour gradient icon squares).

## Look
- Canvas cream `#FBF6EC`; cards `#FFFDF8` with `1.5px solid #E9DFCD` border, radius 22–24px, shadow `0 2px 0 #EFE6D6` (+ optional `0 14px 28px -20px rgba(27,21,48,.22)`). No backdrop-filter, no glass, no glow.
- Ink `#1B1530`, text-2 `#4A4560`, muted `#615B74`/`#6E6880`. One violet `#5B2BFF` (text-violet `#3A10D8`, edge `#2A0BA6`), tint `#EFE9FF`. Saffron `#F6B93B` (edge `#D99A1E`, tint `#FFF3D6`, ink `#7A5A1A`). Tomato `#EF5A3C` (text `#C8432A`, tint `#FFE9DE`). Sky `#9EC5FF` / tint `#E6F0FF`. Mint (LCD only) `#9EF5C4`. Status: ok `#1E7F55` tint `#E3F5EA`, warn `#A66300`, bad `#C8432A`. Use the CSS variables from v2.css (`--paper --rim --rim-2 --edge-b --accent --accent-ink --accent-edge --tint --saffron* --tomato* --sky* --ok --warn --bad --tint-*`).
- **No gradients** except the violet grid « wall » (class `.wall`, or `background-color:var(--wall);background-image:var(--wallbg);background-size:22px 22px`) for at most one hero per screen.
- Fonts: display/titles/big numbers = `var(--d)` Bricolage Grotesque (weights 700–780, letter-spacing −.02 to −.035em); text = `var(--f)` Instrument Sans (500–700); fridge LCD / codes = `var(--lcd)` JetBrains Mono. `.mono` now means Bricolage tabular numbers.
- Icons: round wells (`border-radius:50%`) with a pastel tint and a coloured stroke icon (e.g. violet on `#EFE9FF`, saffron-ink on `#FFF3D6`, sky-ink `#2F5FBF` on `#E6F0FF`, tomato on `#FFE9DE`, white on ink for the scanner). Never gradient squares.
- Buttons are tactile: they sit on a darker bottom edge (`box-shadow:0 4px 0 <edge>`) and press down (`:active{transform:translateY(4px);box-shadow:none}`). Primary violet/edge `#2A0BA6`; dark ink/edge `#000`; light cream/edge `#E2D6C2` with inset rim `#DCCFB8`; saffron/edge `#D99A1E`; tomato/edge `#A93520`.
- Labels: sentence case, 12–13px, weight 650; avoid ALL-CAPS letter-spaced labels. Pills soft; Marceau dislikes **small green dots/ticks next to text** — remove those decorations.
- Motion: springy (`cubic-bezier(.34,1.56,.64,1)`), staggered `.st` entrances, presses that sink. Respect prefers-reduced-motion.
- Less text: shorten sub-lines where they are long; one clear action per card.
- Phone first (390px), then tablet (820px) and desktop (1366px, sidebar 256px).
